# 로컬 Codex 분석 작업

`prepare.mjs`의 출력에 포함된 후보 메타데이터와 한국어 자막의 `start`, `duration`, `text`만 근거로 사용한다. 외부 LLM API를 호출하지 않는다. 영상의 사실성·아동 적합성은 자막과 영상 원본을 함께 살펴보고 판단한다. 자막만으로 화면의 부적절성이나 최신 법·제도의 정확성을 확정할 수 없으면 `reason`에 교사 검토 사항을 적는다.

1. 초등 적합성, 교육 가치, 흥미도, 사실 신뢰성을 각각 1~5로 판단한다. 공식 기관 여부를 점수나 자동 채택 기준으로 사용하지 않는다.
2. `education_topics`의 실제 slug에서 주제와 세부주제를 고른다. 한 영상에 여러 주제를 붙일 수 있다. 권장 학년대, 영상 요약, 핵심 개념, 수업 활용 유형, 최신성 유형을 작성한다.
3. 자막을 처음부터 끝까지 훑고 읽을 수 있는 구간의 서로 다른 핵심 학습 내용을 시간대별로 정리한다. 이야기 전개·인사·반복 장면은 학습 내용으로 세지 않는다. 각 핵심 내용이 문제에 반영됐는지 대조한 뒤 자막에 명시된 내용으로만 빈칸 문제를 만든다. 빈칸은 이름이나 순서 암기보다 학생이 실제로 해야 할 행동·판단 또는 핵심 개념을 확인하는 말에 둔다. 영상 자막에 없는 용어를 문제 문장에 끼워 넣지 않는다. `꼭 지켜요`처럼 무엇을 해야 하는지 드러나지 않는 문장은 문제로 만들지 않는다. 문제당 `@@BLANK@@` 하나, 정답 하나를 사용한다. 사소한 숫자, 모호한 정답, 영상 밖 지식은 피한다. 같은 수칙의 표현만 바꿔 문제 수를 채우지 않는다. 문제 수는 영상 길이보다 읽을 수 있는 핵심 내용의 수에 맞춘다.
4. 각 문제에 자막에서 그대로 따온 `evidence_text`와 실제 자막 구간의 `evidence_start_seconds`, `evidence_end_seconds`를 넣는다. 정답이 `evidence_text`에 실제 들어 있어야 한다.
5. **별도 의미 검증:** 문제와 정답을 `evidence_text`만 보고 풀 수 있는지 다시 판단한다. 통과한 문제에만 `semantic_validation: {"passes": true, "reason": "..."}`를 쓴다. 실패 문제는 JSON에서 제외한다. `commit.mjs`도 문자열·시간 구간·의미 검증 결과를 확인한다.
6. `coverage_review`에 읽을 수 있는 핵심 내용마다 어떤 문제 번호로 다뤘는지 기록한다. 교육적으로 중요하지만 빈칸 문제로 만들지 못한 항목은 누락 이유를 적는다. 확인되지 않는 자막 구간은 문제 근거로 쓰지 않는다.
7. `analysis.example.json` 형식으로 저장한다. `decision`은 `needs_review`로 고정한다. JSON에 전체 자막이나 세그먼트 배열을 포함하지 않는다.

자동 검증은 문자 근거와 시간 일치를 확인할 수 있지만 의미·사실성 판단을 대체하지 않는다. 교사가 공개 전에 영상을 직접 검수한다.
